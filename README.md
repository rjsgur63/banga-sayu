# 반가워, 사유 (웹 배포본)

HCI 설계 D조 웹 게임의 GitHub Pages 배포 폴더입니다.

- `index.html`: 이 주소(QR)로 들어오면 바로 `시각장애인판/index.html`의 첫 화면(노란 큰 단추 '소리로 시작')으로 보냅니다.
  오리지널은 그 화면의 '보면서 하기'로 갑니다. (v2 · 2026-11-22 교수님 피드백 반영. 11/20 판에서는 두 판 중 하나를 고르는 화면이었는데,
  화면 낭독기가 멈추는 곳이 9개라 '한 화면 5개 이하'를 넘었습니다. v3에서도 이 파일은 그대로이고,
  규칙은 '본문 4곳 이하 + 맨 아래 이동 단추 3개'로 바뀌었습니다.)
- `오리지널/index.html`: 사유자의 시련(약 30분)
- `시각장애인판/index.html`: 소리로 만나는 판(약 18분, '소리로 시작' · 화면 낭독기 지원)
- `v3/`: 맨 위로 옮기기 전에 폰 시험용으로 먼저 올린 v3입니다. 안의 세 파일은 맨 위의 같은 이름 파일과 똑같습니다.
  시험 주소(`.../banga-sayu/v3/`)가 계속 열리도록 남겨 두었습니다.
- `sw.js`: 예전 판이 이 주소에 남긴 서비스 워커(오프라인 캐시)를 지우는 파일. 지우지 마세요.

v3(2026-11-24)에서 바뀐 것:
- 두 판 모두 모든 화면 맨 아래에 [이전] [건너뛰기] [처음으로] 단추가 늘 같은 순서로 있습니다.
- 시각장애인판의 네 시련(거인 · 전시실 1방 · 2방 · 만남)은 모두 [다음 듣기]와 [고르기] 두 단추로 합니다.
  만남은 떨리는 소리가 날 때 [고르기]를 누릅니다.
- 시각장애인판 첫 화면의 '보면서 하기'는 큰 단추가 아니라 오른쪽 위 작은 글자 링크입니다
  (눈으로 보고 누르는 사람용이라 화면 낭독기 · Tab 차례에는 없습니다).
- 시각장애인판은 v2에서 저장한 진행을 이어 가지 않고 처음부터 시작합니다(저장 형식이 바뀌었습니다).
  오리지널은 v2 진행을 그대로 이어 갑니다.
- `v3/` 시험 주소에서 해 본 기기는 저장을 같이 써서 맨 위 주소에서도 노란 큰 단추가 [이어하기]로 나옵니다.
  전시용 폰은 '설정과 다른 방법 → 처음부터 새로 하기'로 지워 두세요.

두 판 모두 그림, 소리, 영상까지 한 파일에 들어 있어서, 그 `index.html` 하나만 열어도 바로 시작합니다.
오리지널 시작 화면의 "소리로 만나는 판으로 가기" 링크는 옆 폴더 `../시각장애인판/index.html`로,
시각장애인판 첫 화면의 '보면서 하기'는 `../오리지널/index.html`로 갑니다.

## 새 판으로 바꾸는 법

1. 게임 폴더에서 `python3 build.py`를 실행합니다(`dist/`, `dist-blind/`가 새로 생김).
2. `dist/index.html`은 `오리지널/index.html`로, `dist-blind/index.html`은 `시각장애인판/index.html`로 덮어씁니다.
   (v3 · 2026-11-24: 두 판 모두 v3 빌드로 바꿨습니다. `index.html`은 빌드 결과물이 아니라 손으로 쓴 작은 파일이라 그대로 둡니다.)
3. 커밋하고 `git push` 합니다. 1~2분 뒤 사이트에 반영됩니다.

파일 하나가 25MB를 넘어서 GitHub 웹 화면의 끌어다 놓기로는 올라가지 않습니다. `git push`나 GitHub Desktop을 쓰세요(한 파일 한도 100MB).
